# Assumptions

- The supplied challenge text did not contain the exact vertical or track names, so the README labels them as assumptions rather than inventing names.
- The first implementation prioritizes a working offline image pipeline and transparent fallbacks.
- No personal images, external datasets, or model weights are bundled.
- The v2 investigation platform uses the existing README vertical
  “media provenance and evidence” and the user-provided track name because
  the exact challenge document was not attached.
- The existing `/api/v1` API remains a compatibility boundary while v2 is
  added under `/api/v2`.

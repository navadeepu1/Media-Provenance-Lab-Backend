# Evaluation artifacts

`manifest.json` and `results.json` are generated by `scripts/generate_eval.py`.
The generated samples are original synthetic outputs of this repository and are
released under CC0-1.0 for evaluation and regression use.

This is not a real-world accuracy benchmark. Labels describe the deterministic
generator intent, not human forensic ground truth. The reported metrics measure
whether the pipeline emitted a weak/strong evidence tier for these synthetic
inputs; they must not be presented as production detector accuracy.

Regenerate from the repository root:

```powershell
python scripts/generate_eval.py
```
